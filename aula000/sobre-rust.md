# 🧠 Paradigmas da Linguagem Rust

Rust é considerada uma linguagem **multiparadigma**, oferecendo suporte para diferentes estilos de programação.

### 📌 Programação Imperativa

Execução do código através de comandos em sequência.

### 📌 Programação Estruturada

Organização do código utilizando:

- Funções
- Estruturas de controle
- Laços de repetição
- Modularização

### 📌 Programação Orientada a Objetos (Parcial)

Rust não possui herança clássica, porém oferece recursos como:

- Structs
- Traits
- Encapsulamento
- Polimorfismo através de Traits
